## 2. 시스템 논리/물리 전체 아키텍처 구성도 (Architecture Diagram)

### 2.1 5-Tier 엔터프라이즈 계층 구성도
```
[ 1. Presentation Layer (클라이언트 영역) ]
  ├── 웹 통합 관제 대시보드 (React 18 + TypeScript + TailwindCSS SPA)
  ├── 모바일 필드 관제 웹 (PWA 반응형 웹)
  └── 시스템 운영·관리자 콘솔 (RBAC 기반 대시보드, 감사 이력, RTM 추적)
         │  ▲  (HTTPS / TLS 1.3 / WSS WebSocket Secure)
         ▼  │
[ 2. Gateway & Security Layer (경계 보안 및 인증 영역) ]
  ├── Nginx Reverse Proxy (SSL 오프로딩, 정적자원 Gzip 서빙, L7 로드밸런싱)
  ├── Web Application Firewall (WAF, SQL 인젝션/XSS 차단, DDoS 방어)
  └── API Gateway & Auth Broker (Spring Security, JWT Bearer, 2FA OTP)
         │  ▲  (/api/* 내부 마이크로서비스 라우팅)
         ▼  │
[ 3. Application / WAS Layer (비즈니스 코어 - 전자정부 표준프레임워크 4.0) ]
  ├── 디바이스 & FMS 관제 서비스 (3초 단위 텔레메트리 파싱, 이상 상태 감지)
  ├── 핵심 비즈니스 & 정산 엔진 (사용자/장비 관리, 통계 배치 집계, 이벤트 알람)
  └── 실시간 이벤트 브로커 (Spring WebSocket + Redis Pub/Sub 브로드캐스팅)
         │  ▲  (HikariCP 커넥션 풀 / 비동기 큐)
         ▼  │
[ 4. Data & Persistence Layer (데이터 및 저장소 영역) ]
  ├── PostgreSQL 15 (ACID 관계형 마스터 DB, 메타데이터, JSONB 이력 관리)
  ├── PostGIS (GPS 공간 좌표 인덱싱(GiST), 지오펜싱, 반경 고속 탐색)
  ├── Redis 7.0 Cluster (실시간 관제 최신 캐시, 세션 클러스터링, 분산 락)
  └── MinIO / S3 Storage (UAT 시험 성적서, 준공 산출물 패키지, 감사 로그)
         │  ▲  (REST Client / TCP / MQTT / SFTP)
         ▼  │
[ 5. External Integration & Edge Layer (외부 연계 및 하드웨어) ]
  ├── FMS 단말기 / IoT 센서 (차량 OBD-II, GPS 텔레메트리 스트리밍)
  ├── 공공데이터포털 OpenAPI (기상청 실시간 날씨, 국토교통부 표준 링크)
  └── 고객사 레거시 기간계 (인사/조직 DB 연계, EAI/ESB, 배치 정산 전송)
```

### 2.2 계층별 상세 기술 스펙 및 보안 요건
| 계층 | 구성 컴포넌트 | 주요 역할 | 프로토콜 및 보안 기술 요건 |
|:---|:---|:---|:---|
| **L1. Presentation** | React 18, TypeScript, Tailwind | 반응형 관제 UI, 대시보드 | TLS 1.3 암호화, WSS 실시간 통신 |
| **L2. Gateway/Security** | Nginx, Spring Cloud Gateway | SSL 오프로딩, 인증/인가 | WAF 공격 차단, JWT Bearer, 2FA OTP |
| **L3. Application** | eGovFrame 4.0, Spring Boot 3 | 관제 비즈니스 로직, 알림 | 트랜잭션 격리, 시큐어 코딩 가이드 준수 |
| **L4. Data/Storage** | PostgreSQL 15, PostGIS, Redis | 데이터 영속화, 캐시, GIS | AES-256 컬럼 암호화, 일일 자동 백업 |
| **L5. Integration** | MQTT Broker, REST Client | 차량 단말 연계, 공공데이터 | 상호 TLS(mTLS), 전용선 IP 화이트리스트 |

## 3. 데이터 모델 (ERD) 핵심 엔터티 정의

| 엔터티명 | 물리 테이블명 | 역할 및 설명 | 주요 컬럼 (PK, FK) | 인덱스 전략 |
|:---|:---|:---|:---|:---|
| **사용자** | `TB_USER` | 시스템 접근 관리자 계정 정보 | `user_id`(PK), `email`, `password_hash`, `role` | `email`(Unique Index) |
| **디바이스** | `TB_DEVICE` | 관제 대상 단말/장비 정보 | `device_id`(PK), `serial_no`, `status`, `lat`, `lng` | `serial_no`(Unique), `geom`(GiST) |
| **관제이력** | `TB_TELEMETRY` | 3초 단위 시계열 수집 데이터 | `telemetry_id`(PK), `device_id`(FK), `payload`, `created_at` | `(device_id, created_at DESC)` 복합 인덱스 |
| **이상경보** | `TB_ALARM` | 지오펜스 이탈/고장 이벤트 | `alarm_id`(PK), `device_id`(FK), `alarm_type`, `resolved_yn` | `(resolved_yn, created_at)` 인덱스 |

## 4. 엔드투엔드 서비스 업무 흐름도 (Service & Business Workflow)

### 4.1 서비스 트랜잭션 핵심 업무 흐름도
```
[사용자/단말 요청]
       │ (1. HTTPS / WSS / MQTT 요청 발생)
       ▼
[Nginx & Gateway]
       │ (2. WAF 보안 필터링 ──▶ JWT 유효성 검증 ──▶ 2FA 인가)
       ▼
[eGovFrame Core Service]
       │ (3. 트랜잭션 격리 하에 비즈니스 규칙 처리 및 지오펜스 검사)
       ├───▶ [Redis Pub/Sub & WebSocket] (4. 관제 브라우저 전수 실시간 브로드캐스팅)
       └───▶ [PostgreSQL & PostGIS]     (5. 이력 데이터 영속화 커밋 및 감사 로그 적재)
       │
       ▼
[클라이언트 대시보드]
         (6. 지도 위 마커 실시간 깜빡임, 이상 경보 토스트 알림 노출 완료)
```

### 4.2 예외 및 장애 처리 워크플로우
1. **단말 통신 단절 감지**: 3회(9초) 연속 미수신 시 단말 상태를 '미통신(경고)'으로 자동 전환 및 관제 화면에 노란색 뱃지 표출
2. **지오펜스 이탈 경보**: 허가 구역 외 좌표 수신 즉시 경보(TB_ALARM) 생성 ──▶ 관리자 화면 팝업 및 SMS/알림톡 발송
3. **네트워크 순단 복구**: 클라이언트 재접속 시 Redis 캐시의 최신 스냅샷을 우선 로딩하여 화면 깜빡임 없이 연속 관제 보장

## 5. 주요 화면 흐름도 및 화면 정의 (UI Flow)

### 5.1 전체 메뉴 구조도 (Information Architecture)
```
통합 관제 플랫폼
├── 1. 실시간 모니터링 (메인 대시보드: SCR-01)
│     ├── 전체 지도 뷰 (마커 클러스터링)
│     └── 디바이스 상세 드로어 (텔레메트리 차트: SCR-02)
├── 2. 이력 및 통계 조회 (SCR-03)
│     ├── 기간별 운행 경로 리플레이
│     └── 가동률 / 고장 통계 엑셀 다운로드
└── 3. 시스템 운영 관리 (SCR-04)
      ├── 디바이스 등록 / 관리
      ├── 사용자 및 권한 관리 (RBAC)
      └── RTM 요구사항 추적 및 산출물 다운로드
```

### 5.2 화면 ID: SCR-01 (통합 관제 메인 대시보드)
- **화면 목적**: 전체 디바이스 현황 및 이상 경보 실시간 시각화
- **대응 요구사항**: `REQ-F01`, `REQ-F02`, `REQ-NF01`
- **주요 UI 컴포넌트**:
  1. **상단 글로벌 네비게이션**: 시스템 타이틀, 실시간 상태 인디케이터(3초 갱신), 알림 뱃지, 사용자 프로필
  2. **좌측 상태 요약 패널**: 상태별 디바이스 통계 카드 (전체/정상/주의/미통신) 및 실시간 필터 버튼
  3. **중앙 관제 영역**: 전체화면 지도 뷰 (카카오맵/OpenLayers, 마커 클러스터링, 이상 장비 깜빡임 애니메이션)
  4. **우측 슬라이드 드로어**: 선택 디바이스 상세 텔레메트리 차트 (속도, 배터리, 통신 품질 최근 1시간 추이)
- **예외 UI 대응**:
  - 통신 단절 시 상단 배너에 "실시간 연계 재연결 중 (재시도 N회)" 토스트 노출
  - 이상 경보 발생 시 화면 우측 상단에 플로팅 경보 알림 카드 및 비프음 재생
