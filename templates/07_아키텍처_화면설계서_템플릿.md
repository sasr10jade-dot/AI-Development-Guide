## 4. 주요 화면 흐름도 및 화면 정의 (UI Flow)

### 화면 ID: SCR-01 (통합 관제 메인 대시보드)
- **화면 목적**: 전체 디바이스 현황 및 이상 경보 실시간 시각화
- **주요 UI 컴포넌트**:
  1. 상단 글로벌 네비게이션: 시스템 타이틀, 알림 뱃지, 사용자 프로필
  2. 좌측 패널: 디바이스 상태별 통계 카드 (정상/주의/경고/미통신)
  3. 중앙 영역: 전체화면 지도 뷰 (지도 위 마커 클러스터링 및 실시간 깜빡임)
  4. 우측/하단 드로어: 선택 디바이스 상세 텔레메트리 차트 (최근 1시간 추이)
- **예외 UI 대응**: 통신 단절 시 상단 배너에 "실시간 연계 재연결 중 (재시도 N회)" 토스트 노출
